# คู่มือแอพ Android ของ Parkly

อ่านคู่มือติดตั้งและใช้งานทั้งสามแอพที่ **[Mobile app/Readme_appAndoird.md](Mobile%20app/Readme_appAndoird.md)**

เปิดโฟลเดอร์ `Mobile app/Android` ใน Android Studio แล้วเลือก `renterDebug`, `landlordDebug` หรือ `adminDebug` มีคำแนะนำการตั้งเซิร์ฟเวอร์ สร้าง APK ติดตั้งบนมือถือ สร้าง Admin และเซ็น Release ครบในคู่มือ

ยังไม่ได้ build APK สำเร็จหรือทดสอบบนมือถือจริง เนื่องจากเครื่องพัฒนาไม่มี Android SDK ดู [ผลตรวจจริง](Mobile%20app/Android/VERIFICATION.md)

คู่มือ iOS เปลี่ยนชื่อเป็น [Readme_appIOS.md บน branch IOS-App](https://github.com/Svinyoo/Lorjod/blob/IOS-App/Readme_appIOS.md) แล้ว
