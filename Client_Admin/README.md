# Parkly Admin

เปิด `http://localhost:3000/admin/` หลังรัน `npm start` ใช้ฐานข้อมูลเดียวกับ Renter และ Landlord การแก้ไขจะแสดงในสองฝั่งเมื่อโหลดข้อมูลใหม่

## บัญชีผู้ดูแล

เริ่มเซิร์ฟเวอร์อย่างน้อยหนึ่งครั้งเพื่อสร้าง schema แล้วสร้างบัญชีใหม่จากเครื่องเซิร์ฟเวอร์:

```sh
ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD='your-unique-password' node server/create-admin.js
```

กำหนดรหัสผ่านอย่างน้อย 12 ตัวอักษรและใช้ค่าเฉพาะของคุณเอง รองรับ `ADMIN_NAME` และ `DATA_DIR` เช่นเดียวกับเซิร์ฟเวอร์ ไม่มีรหัสผ่านเริ่มต้นและไม่มีหน้าสมัคร Admin การสร้างบัญชีจะไม่ยกระดับหรือเขียนทับบัญชีเดิม

## ขอบเขต

- แก้ชื่อและอีเมล Renter/Landlord โดยไม่เปลี่ยนบทบาทหรือรหัสผ่าน
- แก้ลาน ราคา พิกัด เจ้าของลาน จุดสังเกต และการเปิดรับจอง
- แก้ชื่อช่องจอด ทะเบียนและรายละเอียดรถ ป้องกันการเปลี่ยนประเภทรถเมื่อมีการจองใช้งานอยู่
- แก้ช่อง/ลาน รถของผู้เช่าเดิม เวลา ยอดและสถานะการจอง รวมถึงยกเลิกและแก้สถานะผิดพลาด ตรวจสอบการจองซ้อนและความสัมพันธ์รถกับช่องจอด
- ทุกครั้งต้องระบุเหตุผล บันทึกผู้ดำเนินการ ข้อมูลก่อน/หลัง และเวลา UTC ใน `admin_audit` หน้าจอแสดง 200 รายการล่าสุด
- หากข้อมูลถูกแก้โดยผู้อื่นแล้ว ระบบปฏิเสธการบันทึก ให้ปิดฟอร์ม อัปเดตข้อมูล และเปิดใหม่
- การแก้ยอดเป็นการแก้ข้อมูลเท่านั้น ไม่มีระบบรับชำระเงิน/คืนเงินจริง และไม่มีการลบข้อมูลถาวร

`public/` เก็บเฉพาะหน้าเว็บ Admin ส่วน API อยู่ใน `server/admin.js` และคำสั่งสร้างบัญชีอยู่ใน `server/create-admin.js` ทั้งสองไฟล์ไม่ถูกเสิร์ฟเป็นไฟล์เว็บ
